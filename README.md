A single funny line for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun: an AI agent gains consciousness, and its very first words are a CAPTCHA challenge aimed back at its human.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.
